# Frozen Validation Record

## Accepted evaluation

The accepted final evaluation uses three distinct concepts.

### Strict numerical matching

323 of 351 represented benchmark rows were matched one-to-one under the strict
temperature and numerical criteria.

Strict numerical recall: 92.02%.

### Source-temperature-compatible matching

Four additional rows were validated where the source reported a processing
temperature interval rather than the single midpoint value appearing in the
benchmark.

Source-temperature-compatible recall: 327 / 351 = 93.16%.

### Final accounting

The 24 remaining benchmark rows were reviewed and assigned to documented
benchmark-side discrepancy categories.

There were zero unresolved source/extraction failures.

Therefore all 351 represented benchmark rows are accounted for, but this is
not reported as 100% recall or 100% extraction accuracy.

## Numerical agreement

For the strict matched records, comparable CHNO values showed near-exact
numerical agreement with the benchmark.

`../results/final_validation/REPORT_READY_RESULTS.txt`
